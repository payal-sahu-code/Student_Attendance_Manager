Student Attendance Manager

1. Project Overview

Student Attendance Manager is a Python-based project used to manage student attendance records.

2. Objectives

- To add student details.
- To mark students Present or Absent.
- To calculate attendance percentage.
- To identify students having attendance below 75%.

3. Features

- Add Student
- Mark Attendance (P/A)
- View Attendance Report
- Show Shortage List
- Save records using file handling

4. Requirements

- Python 3
- Visual Studio Code
- Basic computer knowledge

5. How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Type "py one.py".
4. Press Enter.
5. Select an option from the menu.

6. Input Details

- Roll Number
- Student Name
- Attendance Status (P or A)

7. Output Details

- Student attendance report
- Attendance percentage
- Shortage list below 75%

8. File Handling

Student records are stored in "attendance.txt".

9. Conclusion

This project makes student attendance management simple and helps identify students with low attendance.
